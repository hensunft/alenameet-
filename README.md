# Для Алёны ♡

Небольшой одностраничный сайт-приглашение на свидание: вопрос с убегающей кнопкой «Нет»,
конверт, который открывается и превращается в приглашение, и форма, которая отправляет
адрес в Telegram.

**Стек:** React 19 + TypeScript + Vite, Tailwind CSS 4, Motion (Framer Motion), Lucide React,
serverless-функция Vercel для `/api/rsvp`.

## Сценарий

1. **Вопрос** — «Алёна, пойдёшь со мной на свидание?» и кнопки «Да» / «Нет».
   «Нет» уворачивается от курсора и пальца. После 5 попыток под карточкой появляется
   неброская ссылка «Ответить «нет»».
2. **Переход** — «Тогда у меня для тебя кое-что есть» и кнопка «Открыть».
3. **Конверт** — тап: конверт чуть увеличивается, клапан открывается, письмо выезжает,
   конверт уходит вниз, письмо разворачивается в карточку.
4. **Приглашение** — дата и время, поле «Откуда тебя забрать?», отправка в Telegram.
5. **Финал** — «До встречи ♡».

## Настройки и тексты

Всё, что можно менять, лежит в [`src/config/invitation.ts`](src/config/invitation.ts):

```ts
export const invitationConfig = {
  recipientName: "Алёна",
  senderName: "Рома",
  date: "2026-10-15", // YYYY-MM-DD → «15 октября», «четверг», «15.10.2026»
  time: "19:30",
  title: "Приглашение на свидание",
  subtitle: "Буду рад увидеть тебя снова ♡",
};
```

Там же объект `texts` со всеми надписями интерфейса и сообщениями об ошибках.
Сервер берёт дату, время и имя из того же файла, поэтому сообщение в Telegram всегда
совпадает с тем, что видно на сайте.

Заголовок вкладки и Open Graph теги — в [`index.html`](index.html),
картинка превью — [`public/og-image.png`](public/og-image.png) (1200×630).

## Локальный запуск

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env   # впишите TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
npm run dev            # http://localhost:5173
```

`npm run dev` поднимает и фронтенд, и `/api/rsvp` (через небольшой плагин в
[`dev/apiDevServer.ts`](dev/apiDevServer.ts)), так что отправку можно проверить без Vercel CLI.
Для проверки с телефона в той же сети откройте адрес из строки `Network`.

Остальные команды:

```bash
npm run typecheck   # проверка TypeScript (фронтенд, API, конфиг Vite)
npm run build       # typecheck + production-сборка в dist/
npm run preview     # просмотр production-сборки (без API)
```

## Telegram-бот

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен — это `TELEGRAM_BOT_TOKEN`.
2. Откройте своего нового бота и нажмите **Start** (без этого бот не сможет написать вам).
3. Узнайте свой chat id — например, напишите [@userinfobot](https://t.me/userinfobot)
   или откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после сообщения боту
   и возьмите `message.chat.id`. Это `TELEGRAM_CHAT_ID`.

Сообщение приходит в таком виде:

```
💌 Ответ на приглашение

Алёна согласилась на свидание.

📅 15.10.2026
🕢 19:30
📍 Адрес: …
```

## Деплой на Vercel

1. Загрузите репозиторий на GitHub.
2. На [vercel.com/new](https://vercel.com/new) импортируйте репозиторий.
   Framework Preset определится как **Vite**, остальные настройки уже есть в `vercel.json`.
3. В **Settings → Environment Variables** добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`
   (окружение Production, при желании и Preview).
4. Нажмите **Deploy**. Если переменные добавлены после первого деплоя — сделайте **Redeploy**.
5. Откройте сайт, пройдите сценарий и отправьте тестовый адрес — сообщение должно прийти в Telegram.

Через Vercel CLI:

```bash
npm i -g vercel
vercel                                    # первый деплой и привязка проекта
vercel env add TELEGRAM_BOT_TOKEN production
vercel env add TELEGRAM_CHAT_ID production
vercel --prod
```

**Превью ссылки в Telegram.** Для `og:image` нужен абсолютный адрес. На Vercel он подставляется
при сборке автоматически из `VERCEL_PROJECT_PRODUCTION_URL`. Если используете свой домен,
добавьте переменную `SITE_URL=https://ваш-домен` и пересоберите проект. Telegram кэширует превью —
если ссылку уже отправляли до деплоя, обновите его через [@WebpageBot](https://t.me/WebpageBot).

## Безопасность и приватность

- Токен и chat id есть только в переменных окружения сервера и не попадают в клиентский бандл.
- `/api/rsvp` принимает только `POST` с `application/json` и того же origin, тело — до 4 КБ.
- Адрес очищается от управляющих и невидимых символов, длина — до 300 символов
  (проверяется и на клиенте, и на сервере). Сообщение уходит без `parse_mode`,
  поэтому ввод не может повлиять на разметку.
- Ограничение частоты: 5 отправок с одного IP и 30 всего за 10 минут (ответ `429` с `Retry-After`).
  Лимит хранится в памяти функции — для такого сайта этого достаточно; для жёсткого глобального
  лимита понадобится внешнее хранилище (например, Upstash Redis).
- Адрес не пишется в логи, не сохраняется в `localStorage` и не попадает в URL.
  В логах только коды ошибок Telegram API.
- Успех показывается только после ответа сервера `{ ok: true }`. При ошибке — понятное сообщение
  и кнопка «Отправить ещё раз».
- Никакой аналитики и сторонних запросов: шрифты встроены в сборку,
  `vercel.json` задаёт строгий Content-Security-Policy и запрещает доступ к камере,
  микрофону и геолокации.

## Мобильные устройства

- Вёрстка от 320 px, учитываются `safe-area-inset-*` (вырез и home indicator на iPhone).
- Поле ввода — 16 px, поэтому iOS Safari и встроенный браузер Telegram не увеличивают
  страницу при фокусе. Масштабирование при этом не запрещено.
- Убегающая кнопка работает на касание (`pointerdown`), остаётся в видимой области
  с учётом safe area, не закрывает вопрос и кнопку «Да» и не создаёт горизонтальной прокрутки.
- `prefers-reduced-motion`: покачивание отключается, переходы становятся простым плавным появлением.

## Структура

```

dev/apiDevServer.ts            запуск /api/* при `npm run dev`
src/config/invitation.ts       настройки и все тексты
src/lib/                       дата, запрос к API, расчёт позиции кнопки «Нет», параметры анимаций
src/components/
  WelcomeScreen.tsx            вопрос
  MovingNoButton.tsx           убегающая кнопка «Нет»
  DeclineScreen.tsx            спокойный ответ на отказ
  TransitionScreen.tsx         «Тогда у меня для тебя кое-что есть»
  EnvelopeScreen.tsx           экран конверта
  EnvelopeAnimation.tsx        конверт: слои, клапан, выезд и разворот письма
  InvitationScreen.tsx         содержимое приглашения и форма
  SuccessScreen.tsx            «До встречи ♡»
```
